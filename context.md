Tech stack:
- Next.js
- React
- Tailwind CSS
- Node.js
- Drizzle ORM
- PostgreSQL

Project idea:
Skillful is a platform for users to gain skills in various areas of life. We will first begin with improving basketball skills, then expand to other areas like cooking, communication, piano, etc.

For the UI, we want a clean, non-cluttered, modern, and sleek look. Using hexagons to represent skills is a must. The color scheme will be black, gold, and white, with hints of red for accents.

For the actual logic, we want to use a system where users can track their progress in various skills. This will be done by having a main skill, and then sub-skills under that main skill. For example, under basketball, we can have sub-skills like dribbling, shooting, passing, etc. Each sub-skill will have a certain level, and the user can increase the level of the sub-skill by practicing it.

To start, I will provide a predefined list of skills and sub-skills for basketball. We can add more later if needed. But it needs to be adaptable to other skills as well. And have the ability to generate a skill tree for each skill later on. 

For basketball:

Main skill: Basketball

Sub-skills:
- Dribbling
- Finishing
- Shooting
- Passing
- Defense
- Rebounding

For the database, we will use PostgreSQL. We will use Drizzle ORM to interact with the database. 

The code must be well-structured, modular, and easy to maintain. It must also be well-documented and easy to understand. I am a student and I am learning to code, so I need the code to be easy to understand, and explain to recruiters or engineers when I interview.
